Bedrock for Mac 2.0.2 fixes an application shutdown bug that could leave **Install and Restart** displaying “Restarting to install…” without closing the app.

**If you are running 2.0.0 or 2.0.1, install this update using the DMG below.** The faulty shutdown code is in those installed versions, so downloading a newer update cannot repair their restart step. Close the old app, open **Amazon.Bedrock.Client.for.Mac.dmg**, and replace **Amazon Bedrock** in Applications. Conversations and settings are stored separately.

- Save drafts, attachments and local workspace data while the normal application event loop is still running, then approve shutdown.
- Repeated Quit requests share one save operation.
- Failed saves keep the app open and stop the pending installation instead of leaving an indefinite restart status.
- Add real AppKit process tests for asynchronous saving, canceled shutdown, retry, and installation followed by relaunch.
- Keep text selected while a response streams, crosses the long-message threshold, completes Markdown formatting, or finishes code highlighting. Drag direction and formatted selection copy are preserved.

The release retains the streaming, image preparation, document transport and Archive fixes from 2.0.1. It supports Apple silicon and Intel Macs on macOS 14 or later.
