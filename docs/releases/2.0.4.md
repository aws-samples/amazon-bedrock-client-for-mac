Bedrock for Mac 2.0.4 adds Kimi K3 and improves compatibility with newly discovered Bedrock models.

- **Kimi K3:** Chat through Bedrock Runtime Responses using your AWS account and selected US or Global inference profile. Text, images, documents, local tools, MCP tools, and follow-up conversations use the same request path.
- **Compatible parameters:** Omit Kimi K3's unsupported temperature and Top P fields, including values saved before this update. Configure reasoning from Off through Max; turning Thinking off explicitly disables reasoning without erasing the saved effort.
- **Prompt caching:** Use Kimi K3's supported explicit cache controls when prompt caching is enabled, and report cache reads and writes in usage.
- **New model defaults:** Models without built-in inference settings no longer receive arbitrary sampling values or a guessed reasoning configuration. They use service sampling defaults with a bounded output limit. Explicit custom parameters and existing saved preferences remain available.
- **Inference profiles:** Keep application profile ARNs and their billing scope on Converse. Explain the system-profile requirement for Kimi K3 document attachments and omit incompatible reasoning history from Converse requests.

Validation covers model routing, serialized requests, saved settings, document and image bytes, cache controls, reasoning, and tool continuations. Live Bedrock checks verify US and Global profiles in three US regions, attachment content, tool calls, reasoning off, and cache hits.

Update using **Check for Updates**, or download **Amazon.Bedrock.Client.for.Mac.dmg** below. If you are running 2.0.0 or 2.0.1, close the app and install from the DMG; those versions have a shutdown bug that can prevent automatic installation from restarting the app.

Supports Apple silicon and Intel Macs on macOS 14 or later.
