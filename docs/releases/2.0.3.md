Bedrock for Mac 2.0.3 improves model attachments, AWS authentication, MCP connections, and everyday chat controls.

- **GPT image inputs:** Correct the Responses endpoint and image schema for GPT-5.4 and GPT-5.5, including images returned by tools and carried into follow-up messages. Preserve the working Converse image path for GPT-5.6 Luna, Terra, and Sol.
- **Astra documents:** Keep PDF and text attachments on Runtime Responses, including when replaying conversation history. Explain unsupported document requests through application inference profiles before sending, while preserving the attachment.
- **Application inference profiles:** Import a profile directly by ARN, retain its model capabilities, and use the original ARN for Converse requests, billing, and IAM authorization.
- **Claude Sonnet 4.6:** Send compatible sampling parameters when thinking is disabled.
- **Chat titles:** Choose a separate model for automatic title generation in Settings. Manual titles and conversation inference settings remain intact.
- **AWS SSO:** Start sign-in from connection settings, with support for modern SSO sessions and legacy profiles.
- **HTTP MCP authentication:** Initiate OAuth sign-in when required, securely store credentials, and refresh access tokens.
- **MCP context:** Optionally load server tools and usage guidelines on demand. Existing server configurations keep their current behavior.
- **Math rendering:** Render inline and display math offline, preserving code, ordinary currency text, and selection during streaming.
- **Automatic updates:** Show actionable GitHub API and rate-limit errors, honor retry deadlines, and reuse unchanged release metadata.

Validation includes regression tests for model routing, serialized attachments, streaming, application profiles, authentication, title settings, math selection, and update handling. Synthetic PDF, text, and image requests were also checked against live Bedrock endpoints.

Update from 2.0.2 using **Check for Updates**, or download **Amazon.Bedrock.Client.for.Mac.dmg** below. If you are running 2.0.0 or 2.0.1, use the DMG: those versions have a shutdown bug that can prevent automatic installation from restarting the app. Close Amazon Bedrock and replace it in Applications; conversations and settings are stored separately.

Supports Apple silicon and Intel Macs on macOS 14 or later.
