Bedrock for Mac 2.0 brings a focused native workspace for conversations, local tools and Amazon Bedrock models.

[Watch the app tour](https://github.com/aws-samples/amazon-bedrock-client-for-mac/releases/download/v2.0.0/demo.mp4) · [Setup and documentation](https://github.com/aws-samples/amazon-bedrock-client-for-mac/tree/v2.0.0#readme)

### A quieter, faster workspace

- A full-height translucent sidebar, Light / Dark / System appearances, a centered welcome composer, and compact controls.
- Model selection beside the message input, with in-chat model switching and preserved conversation context.
- Global search with Command-K, conversation search with Command-F, and the familiar Command-N / Command-D / Command-B shortcuts.
- Continuous conversation history with lazy offscreen rendering, preserved reading position, and draft updates that avoid rebuilding the whole scene.
- Initial window sizing that fits smaller displays without clipping the sidebar or composer.

### Bring your work into the conversation

- Local file reading, writing, image inspection, conversation search, Git and shell commands, with configurable permissions.
- Reusable skills, MCP tools, inspectable tool inputs and original outputs.
- Durable message queues with editing, pause/resume, stop, and recovery after restart.
- Source files, documents, images and long pasted text; editable text attachments and responsive full-size image previews.
- Bedrock demo presets, local automations and activity history. Automations share the provider-aware model selector and support weekday, timezone and active-hour scheduling. Archive and Trash live together in Settings.

### Built for your Mac and your AWS account

Conversations, skills, queues and preferences stay on this Mac. Inference connects directly to AWS; prompts and selected attachments are sent to the chosen service. Existing local conversations and preferences are migrated in place.

The release contains a signed, notarized universal app for Apple silicon and Intel Macs running macOS 14 or later. Model access, region support and AWS charges depend on your account.

Automatic update checks preserve the existing preference and GitHub release route.
Manual checks are available from the app menu and General settings. Updates verify
the download, application identity, version, and signing team before preparing a
replacement. Installation waits for a graceful quit and restores the previous app
if replacement fails. The DMG retains the volume name and asset name used by the 1.x updater.

Automated validation covers storage and migration, native Markdown and clipboard behavior, MCP subprocesses, image previews, optimized UI interactions, and Bedrock streaming/tool/queue flows through a local protocol fixture. Account-specific model availability remains a live AWS check.

Download **Amazon.Bedrock.Client.for.Mac.dmg**, open it, and drag **Amazon Bedrock** to Applications. `SHA256SUMS.txt` contains the checksum of the notarized DMG.
