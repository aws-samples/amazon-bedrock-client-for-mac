# KaTeX

KaTeX 0.18.7, licensed under MIT. `katex.min.js` comes from the upstream release archive at https://github.com/KaTeX/KaTeX/releases/tag/v0.18.7.

The app uses its MathML output with WebKit’s built-in math layout. No CDN, remote fonts or stylesheets are loaded. Expressions are bounded and rendered with `trust: false` and a finite expansion limit.
